# Windows 单聊天短测

工具源自固定 R2 ZIP。原件的校验清单为上一级 R2-SHA256SUMS。每次运行在当前用户的 Windows 临时目录中新建试验目录，使用独立 Codex 0.164.0、worker 级别的 xterm-256color、gpt-6.1-sol 和 high。使用本机已获授权的测试账号和用户专用临时目录。

```powershell
# 原 2409c40 包
& '.\desktop\run.cmd' $wfc $codex
# 本地构建的包，COMMIT.txt 中的候选标识和打包时记录的 pyz SHA-256
& '.\desktop\run.cmd' $wfc $codex $candidateId $expectedPyzSha256
```

命令窗口会显示 trial 的路径。派发命令的首错及数据库中的创建错误保存在 dispatch-local.json；运行时启动参数、目录和脱敏报错保存在 startup-local.json。这两份记录仅供本机读取。自然退出末屏取自与本次执行匹配的签名回执。尚在运行的错误画面单独标作 live_screen。模型及强度的来源在 evidence/result.json 的 launch_inputs，实际运行值在绑定到 worker 的 turn_context。

对外仅回传脱敏摘要。evidence/result.json 记录启动、正式消息行号、事件投影、报告、done、ACK 和清理回执。evidence/inputs.jsonl 按时序记录回复操作及脱敏屏幕位置。调查启动条件时可直接运行 desktop_probe.py，通过 --worker-term 单独控制 TERM；原包使用默认的固定哈希。

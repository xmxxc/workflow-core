# 单聊天工具 R2

此版用于复核启动取证。Windows 原生 CI 的两路操作和回收范围见上一级 CI.md。在总控决定需要桌面复核时，在既有已验证目录下打开 PowerShell，填本机原候选包和独立 Codex 路径。

```powershell
& 'C:\工具\短测R2\desktop\run.cmd' 'C:\候选包\wfc\wfc.cmd' 'D:\工具\Codex\codex.exe'
```

工作目录为本次新建的 trial/work。实际宿主为固定 0.164.0 原生程序。提供 npm 入口时，脚本验证安装后解析到同一原生 exe。它不修改现有用户配置、模型或权限。

结束后仅回传 evidence/result.json 及存在时的 evidence/inputs.jsonl。启动早退会保存本次错误分类、退出码、脱敏终屏特征、参数哈希和创建身份，随后 close。无法获得的身份会单独注明。宿主未进入绑定的空闲回合时，公开 reply 次数为零。

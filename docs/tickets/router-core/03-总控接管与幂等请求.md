# 03: 总控接管与幂等请求

**What to build:** 从总控派发一个角色任务到结果/提问唤醒，再到异常时可诊断或接替的完整行为；本票只实现标题对应的最小闭环。

**Blocked by:** 02: 消息确认与安全重放.

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 同一 scope 只有一个有效 controller owner
- [ ] 旧 owner 读消息、发送输入、提交结果会被拒绝并可诊断
- [ ] 相同 request ID 重试返回原结果，不同 payload 冲突
- [ ] router 重启后接管不产生双重消费

## Testing boundary

- 通过现有 wfc CLI 和受控宿主替身验证外部行为。
- 不把上层工作流、审查策略或发布动作写入核心。

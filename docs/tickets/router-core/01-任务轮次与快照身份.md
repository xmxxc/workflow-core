# 01: 任务轮次与快照身份

**What to build:** 从总控派发一个角色任务到结果/提问唤醒，再到异常时可诊断或接替的完整行为；本票只实现标题对应的最小闭环。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 每个 dispatch 有稳定 scope、role、round、attempt 身份
- [ ] 下一轮不会覆盖上一轮任务、报告或结果引用
- [ ] router 重启后可以通过 CLI 读取当前和历史轮次
- [ ] 现有 tmux/替身流程回归通过

## Testing boundary

- 通过现有 wfc CLI 和受控宿主替身验证外部行为。
- 不把上层工作流、审查策略或发布动作写入核心。

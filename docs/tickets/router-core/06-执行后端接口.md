# 06: 执行后端接口

**What to build:** 从总控派发一个角色任务到结果/提问唤醒，再到异常时可诊断或接替的完整行为；本票只实现标题对应的最小闭环。

**Blocked by:** 05: 中断与安全接替.

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 执行机制通过 create/inspect/read/submit/interrupt/resume/close 的窄接口接入
- [ ] 核心任务和消息语义不依赖屏幕或具体终端工具
- [ ] 后端返回 definitely-not-sent、accepted、uncertain、refused 等明确结果
- [ ] 现有受控替身测试可复用于至少一个实现

## Testing boundary

- 通过现有 wfc CLI 和受控宿主替身验证外部行为。
- 不把上层工作流、审查策略或发布动作写入核心。

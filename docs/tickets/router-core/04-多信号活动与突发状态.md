# 04: 多信号活动与突发状态

**What to build:** 从总控派发一个角色任务到结果/提问唤醒，再到异常时可诊断或接替的完整行为；本票只实现标题对应的最小闭环。

**Blocked by:** 01: 任务轮次与快照身份.

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 状态区分在线、宿主活动、等待人类、blocked、unknown、completed、failed
- [ ] 计时器或无效输出不能无限掩盖挂起
- [ ] 合法静默和长测试不会被立即误杀
- [ ] 受控替身能触发额度/认证/策略拒绝、权限提示、退出、超时、协议断开、输入未送达和迟到回报
- [ ] 每类宿主故障有稳定机器类别、原始诊断和“需要上层决定”的边界；核心不擅自换模型或重派

## Testing boundary

- 通过现有 wfc CLI 和受控宿主替身验证外部行为。
- 不把上层工作流、审查策略或发布动作写入核心。

# 02: 消息确认与安全重放

**What to build:** 从总控派发一个角色任务到结果/提问唤醒，再到异常时可诊断或接替的完整行为；本票只实现标题对应的最小闭环。

**Blocked by:** 01: 任务轮次与快照身份.

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 完成、提问、阻塞和失败消息拥有稳定 ID 与状态版本
- [ ] 发送未知、已接收、已处理可区分并可查询
- [ ] 相同回执重复提交不重复生效，不同内容返回冲突
- [ ] 中断窗口故障测试通过

## Testing boundary

- 通过现有 wfc CLI 和受控宿主替身验证外部行为。
- 不把上层工作流、审查策略或发布动作写入核心。

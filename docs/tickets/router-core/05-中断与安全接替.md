# 05: 中断与安全接替

**What to build:** 从总控派发一个角色任务到结果/提问唤醒，再到异常时可诊断或接替的完整行为；本票只实现标题对应的最小闭环。

**Blocked by:** 03: 总控接管与幂等请求；04: 多信号活动与突发状态.

**Status:** ready-for-agent

## Acceptance criteria

- [ ] interrupt、close、resume、handoff 有不同结果和审计记录
- [ ] 旧 attempt 失去写入资格后，新 attempt 才能接替
- [ ] 无法确认中断时保持 unknown，不盲目重跑
- [ ] 异常 worker、换宿主和 router 重启均可继续对账

## Testing boundary

- 通过现有 wfc CLI 和受控宿主替身验证外部行为。
- 不把上层工作流、审查策略或发布动作写入核心。

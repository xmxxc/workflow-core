## Windows 快速测试

依赖原生 Windows x64、Python 3.9+、[Herdr 0.9.5 Windows 包](https://github.com/herdrdev/herdr/releases/download/v0.9.5/herdr-windows-x86_64.zip)，以及已安装并登录的 Codex。Herdr/Codex/Node 不包含在 WFC ZIP 中。

解压 WFC ZIP，进入其中的 `wfc` 目录，在 PowerShell 执行：

```powershell
python --version
.\wfc.cmd --version
.\wfc.cmd status
$env:HERDR_SOCKET_PATH = 'wfc-local'
herdr server
```

保持该服务终端运行。在第二个 PowerShell 终端进入同一 WFC 目录。创建任务、报告目录和显式宿主启动配置（Node 与 Codex JS 路径请替换为实际安装位置；若使用原生 Codex exe，可省略 runtime 并将 command 改为其绝对路径）：

```powershell
New-Item -ItemType Directory -Force reports | Out-Null
'先通过 brief 中的 ask 命令问是否可以完成，并结束本轮等待回复；收到回复后，把测试结果写入指定报告，执行 brief 中的 done 命令。' | Set-Content -Encoding utf8 task.md
$launch = @{
  hosts = @{
    codex = @{
      command = @('C:\实际路径\codex\bin\codex.js')
      runtime = @('C:\实际路径\node.exe')
    }
  }
}
[IO.File]::WriteAllText("$PWD\launch.json", ($launch | ConvertTo-Json -Depth 5), [Text.UTF8Encoding]::new($false))
.\wfc.cmd dispatch --backend herdr --herdr-endpoint wfc-local --host codex --task "$PWD\task.md" --cwd "$PWD" --report "$PWD\reports\result.md" --launch-config "$PWD\launch.json"
.\wfc.cmd wait --timeout 60
```

记录返回的 dispatch 和 question id，然后执行：

```powershell
.\wfc.cmd reply <question-id> '可以完成，请写报告并执行 done'
.\wfc.cmd wait --timeout 60
.\wfc.cmd status --dispatch <dispatch-id>
.\wfc.cmd close <dispatch-id>
```

将 `<question-id>` / `<dispatch-id>` 替换成实际值。更多 continue、resume、owner 接替与未知结果处理见 ZIP 中的 `README-Windows.md`、`herdr-backend.md` 和 `host-launch.md`。保留 Python/Herdr/Codex 版本、命令结果、dispatch/attempt 身份及脱敏日志，便于反馈缺陷。

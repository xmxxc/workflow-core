Windows + Herdr 预发布候选，包含 [PR #25](https://github.com/xmxxc/workflow-core/pull/25) 的 OpenCode 2.x 修复：首次 brief 自动提交、新版 SQLite 会话发现、终态错误检测与 resume 识别。保留 Unix tmux 后端。

下载 `wfc-v0.4.7-rc.2-windows-x64.zip`，用同页的 `SHA256SUMS` 核对后解压。进入 `wfc` 目录运行 `wfc.cmd --version`。包中 `COMMIT.txt` 记录构建源码；`OPENCode-Windows.md` 包含完整命令。Python 3.9+、Herdr 0.9.5 和已登录的 OpenCode 需自行准备，Windows 派发显式选 `--backend herdr`，并通过 `--launch-config` 指定 OpenCode 的原生 exe 路径。

优先复测 OpenCode 2.0.12 首派无需手动 Enter 的 ask/reply/done，以及正常退出后恢复原会话。5 分钟 relay 延时另测。

PR #25 的原生 Windows 核心测试和 Herdr 受控宿主合同已通过；该包的真实 Windows OpenCode 闭环仍待实机验收。此前 rc.1 的 Windows 结果使用过人工 Enter，relay 延时为 15 秒。

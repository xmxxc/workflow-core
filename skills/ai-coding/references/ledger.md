# 账本

## 位置

账本放在 `docs/agents/work/ai-coding/<范围>/`，包含 `state.md`、`prompts/` 和 `reports/`。`<范围>` 用短名（票号或主题，如 `113-r17`），重名时再加日期。项目 checkout 不可写时，使用项目 `docs/agents/` 指定的位置；没有指定时，选一个所有接收者都能读的稳定绝对路径，并在首条 Issue 里程碑评论中写明。

只有总控写 `state.md`；worker、审查者和验收方各写自己的具名任务文件或报告。

## 接管

首次接管或范围变化时，读取项目指令、`docs/agents/` 的 tracker、领域和标签配置，以及本范围的规格、Issue/PR 和已有任务。项目未初始化（缺少 `docs/agents/` 的 tracker、标签或领域配置）时，先调用 `setup-matt-pocock-skills` 并完成它原有的交互，再建立账本。

把用户目标固定为：清单、依赖、每票验收条件和开发终点。阻塞原范围的缺陷纳入修复；额外改进记为后续票。同一范围只有一个总控；接续已有任务，不重复准备同票同阶段的任务。

为每个 PR 建立候选身份：

`repo + PR + target + base + merge-base + head + tree`

head、tree、base、需求或标准变化后，旧结论只覆盖原对象，按 [独立审查](review.md) 重新判断覆盖范围。

接管完成的条件：清单、依赖、验收条件、开发终点、派发模式、现有任务、候选身份和标签映射（见 [标签](labels.md)）都已写入 `state.md`。

## 权威来源

| 字段 | 权威来源 |
| --- | --- |
| base、merge-base、head、tree、分支和差异 | Git 对象及远端 PR |
| CI、开放/合并状态、评论与标签发布结果 | 代码托管平台 |
| 任务运行、暂停、结束 | 派发模式的实际证据（见对应 dispatch 文件） |
| 用户目标、票据关系、外部交接 | Issue/PR 及其评论 |
| 调度意图、任务索引、报告入口、历史 | 本账本 |

账本是协调投影，不能覆盖 Git、平台或宿主的实际状态。两者不一致时，把范围标记为 `reconcile-required`，对账完成后再派发、审查或放行。

## state.md

**当前状态区**只放最新事实，就地更新：

- 范围、开发终点、派发模式、总控会话标识、最后对账时间；
- 每票：阶段、候选身份、当前任务（标识、任务文件、报告路径）、最新结论、留痕链接、阻塞和下一动作。

**历史区**按时间追加，不改旧条目。作者自查、独立审查、CI、合并、部署和真实验收各自成条，不互相代替。

## 任务状态

每个状态都要有可核对的证据：

| 状态 | 证据 |
| --- | --- |
| `prepared` | 任务文件已写入 `prompts/` |
| `pending-handoff` | 已交给用户转交或已发送，尚无接收证据 |
| `accepted` | 接收者回执、接手评论或任务对象状态 |
| `running` | 可读的运行状态或接收者进度 |
| `returned` | 报告存在，且要求的留痕已回读确认 |

看不到运行状态的模式可以从 `accepted` 直接进入 `returned`。文件存在、窗口出现或用户说“已转交”只能证明 `pending-handoff`。

**失效**：任务长时间没有回报，并且用户确认它已结束、任务对象已丢失或结束，或者现场只剩未提交的半成品时，标记为 `stale`。保留现场（工作树、未提交内容、日志），用下一轮编号改派，在新任务文件里写明真实起点，以及对旧现场是续用还是放弃。

**范围状态**：`paused`（用户或宿主暂停，保留恢复入口）、`blocked`（缺能力、权限、决定或环境）、`cancelled`（用户取消）、`complete`（达到开发终点或收尾标准）、`reconcile-required`（与权威来源不一致，可与其他状态并列）。

## 意外恢复

遇到上下文压缩、换会话、换模式或换宿主时，先读 `state.md` 的当前状态区，再回读权威来源；状态不一致时先对账。从账本和平台恢复事实，不从上一句对话推断已完成。

## 留痕

- **位置**：Issue 只留里程碑，即开工、PR 链接，以及合并、部署和验收结果。每轮的作者记录、审查记录和处置决定都留在 PR 上。
- **发布前**：回读同票的最新内容；同轮已经发过的，复用原链接。
- **入账**：每条发布都把链接和平台结果记入账本，标签变更记“旧 → 新”。平台拒绝时，把正文存进报告并标记“待发布”，不写成已发布。
- **转录**：总控转录别人的结论时，注明原作者和来源。
- **公开范围**：外部平台只放去敏证据；原始日志、私有标识和凭据按项目的访问边界保存。

总控回读到要求的留痕之后，任务才算 `returned`。缺少留痕时，由你按授权补发转录，或者交回执行者补发。
